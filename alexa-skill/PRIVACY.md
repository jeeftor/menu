# Privacy Policy for School Lunch (Alexa Skill)

Effective Date: 2026-08-18

## What this skill does

The **School Lunch** Alexa skill lets you ask about the school lunch menu for a specific day.

## Information we collect

When you use this skill, Amazon sends the following information to our server at `https://menu.vookie.net/alexa`:

- The date you asked about (for example, "tomorrow", "Monday", or a specific date)
- Your Alexa request metadata (timestamp, request ID, and device locale)

We do **not** collect, store, or process your voice recordings, name, email address, Amazon account ID, or any other personal information through Alexa.

## How we use the information

The requested date is used only to look up the public school lunch menu and generate a spoken response. No request data is stored permanently.

## Data sharing

We do not sell, share, or transfer any data to third parties. The menu content is fetched from a public school nutrition service.

## Security

All requests between Alexa and our server are sent over HTTPS and verified using Amazon's request signature mechanism.

## Changes to this policy

We may update this privacy policy from time to time. The latest version will always be available at the URL referenced in the Alexa skill listing.

## Contact

If you have questions about this privacy policy, please open an issue on the GitHub repository: https://github.com/jeeftor/menu
